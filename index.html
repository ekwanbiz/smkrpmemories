SMKRP MEMORIES

Cari semua gambar anda dari majlis sekolah dengan satu selfie.
1Buka kamera dan pandang ke depan
2Ikut 2 arahan ringkas (pusing kepala / senyum)
3Lihat dan muat turun gambar anda

Selfie anda tidak disimpan. Hanya gambar langsung dari kamera diterima — upload dari galeri tidak dibenarkan.

Pasang app di telefon

Pasang sekali, kemudian buka terus dari skrin utama seperti app biasa.

Android (Chrome)

  1. Tekan menu ⋮ di penjuru kanan atas
  2. Pilih Add to Home screen atau Install app
  3. Tekan Install / Add

iPhone / iPad (Safari)

  1. Buka link ini dalam Safari (bukan dalam WhatsApp atau Chrome)
  2. Tekan butang Share ⬆ di bawah skrin
  3. Skrol dan pilih Add to Home Screen
  4. Tekan Add

Buka dari WhatsApp? Tekan ⋮ dan pilih Buka dalam browser dahulu.
